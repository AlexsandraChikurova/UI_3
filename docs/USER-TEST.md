# Замечания и исправления

Ниже записаны реальные замечания автора во время разработки. Независимое пользовательское прохождение ещё не проводилось.

| Замечание | Исправление |
| --- | --- |
| Нужен вид сверху под углом | Свободное движение в четырёх направлениях, видимые фасады и камера |
| Нужна игра с началом и предысторией | Полноэкранное меню, вступление, кат-сцены и финалы |
| Старый мир не соответствует референсам | Новые иллюстрированные локации, анимация мопса и портреты |
| Механика слишком простая | Дневная посадка и полив, загадка стула, сопоставление улик у часов |
| Изменение предмета нужно слышать | Тихий скрип и мысль мопса после обратного взгляда |
| Карта слишком схематичная, кнопки непонятны | Иллюстрированная карта; подписи «Карта», «Улики» и «Пауза» |
| Отметка мопса закрывает название | Отдельная подпись с лапкой ниже ярлыка места |
| Нет музыки и лая | Восемь музыкальных тем, отдельные регуляторы, лай при действиях и репликах |
| Лай звучит неестественно | Один короткий лай из предоставленной записи, длина 0,5 секунды |

Перед сдачей полезно попросить другого игрока пройти игру без подсказок и записать его наблюдения отдельно.
