# Графика и звук

## Графика

Все используемые изображения лежат в assets/art:

- park.png и park-night.png — парк днём и ночью.
- shop-clean.png — лавка; подвижный стул рисуется отдельно.
- square.png — площадь.
- door.png — сцена у дома №0.
- case-board.png — фон меню.
- town-map.png — карта.
- pug-walk.png — анимация мопса.
- portraits.png — портреты мопса и хранителей.

Референсы других игр и исходные фотографии пользователя не включены в игровой интерфейс.

## Музыка

Восемь оригинальных инструментальных тем реализованы программным синтезом в scripts/generate-audio.mjs. Внешние музыкальные записи и звуковые банки не используются.

| Файл | Тема |
| --- | --- |
| menu.wav | Дело на столе |
| park-day.wav | Солнечные тропы |
| park-night.wav | Лунная пыльца |
| shop-day.wav | Лавка часовщика |
| shop-night.wav | Закрытая дверь |
| square-day.wav | Площадь и фонари |
| square-night.wav | Улица между улицами |
| house.wav | Дом №0 |

Формат музыки — stereo PCM WAV, 22050 Гц, 16 бит. Для пересоздания музыкальных дорожек: `node scripts/generate-audio.mjs`. Готовый короткий лай при этом не перезаписывается.

## Лай

Источник — предоставленный для проекта файл mops-gavknul-i-zatih.mp3. В bark.wav оставлен один лай из участка 1,225–1,5 секунды исходной записи, добавлены мягкие края и небольшой промежуток тишины. Общая длина — 0,5 секунды. Высота голоса не менялась. Исходник в Downloads не изменён.

Звук скрипа создаётся во время игры. Музыка и эффекты отключаются и регулируются отдельно.
