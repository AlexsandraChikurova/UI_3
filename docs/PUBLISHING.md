# Как загрузить игру на GitHub

## Что загружать

Можно загрузить **всё содержимое очищенной папки проекта**. Корневой index.html должен оказаться рядом с папками assets, css и js, а не внутри дополнительной папки «игра».

Минимум для работы опубликованной игры:

```text
index.html
.nojekyll
css/
js/
assets/
```

Остальное удобно оставить в репозитории:

- README.md — описание и управление.
- package.json — команды запуска и тестов.
- tests/ — проверки игры.
- scripts/ — локальный запуск и исходник музыки.
- docs/ — документация и реальные исправления.
- .gitignore — исключения для временных файлов.
- 1 - ЗАПУСТИТЬ ИГРУ.bat — запуск в Windows.

На GitHub Pages Node.js не запускается: браузер использует index.html, css, js и assets. Локальный сервер и тесты нужны только на компьютере разработчика.

## Загрузка через браузер

1. Создайте отдельный репозиторий игры.
2. Нажмите Add file → Upload files.
3. Перетащите файлы и папки изнутри папки проекта. Сохраните вложенность assets/art, assets/audio и остальных папок.
4. Сохраните изменения в ветку main.
5. Откройте Settings → Pages.
6. В Source выберите Deploy from a branch, ветку main и папку /(root); нажмите Save.
7. Дождитесь успешного выполнения публикации во вкладке Actions.
8. Откройте адрес, показанный в Pages. Проверьте новую игру, движение, карту, музыку и гав. После этого добавьте проверенный адрес в начало README.

Публичный адрес появится после публикации. Локальный адрес 127.0.0.1 для отправки преподавателю не подходит.

## Что уже удалено

- Старый PixelRenderer и неиспользуемые методы прежней отрисовки.
- Неиспользуемые тайлы Tiny Town вместе с архивом и каталогом.
- Фон shop.png со старым неподвижным стулом: используется shop-clean.png.
- Прежние скриншоты и промежуточные заметки.
- Служебные пакеты для разовой обрезки MP3 и сам скрипт обрезки.
- Копия полного MP3: в игре используется уже готовый короткий bark.wav. Исходный файл в Downloads не изменён.

Не удаляйте Renderer.js: SceneRenderer наследует из него примитивы рисования и отрисовку вещей. Не удаляйте музыкальные WAV, даже если звучит только одна тема: они загружаются при переходе в другие места и смене суток.
