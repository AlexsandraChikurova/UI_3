# Мопс: После полуночи

Браузерный детектив с видом сверху. Мопс исследует осенний город, ищет забытые вещи по запаху и открывает дорогу к дому №0.

В игре три локации, дневной и ночной мир, диалоги с хранителями, карта, журнал улик и три варианта финала. Музыкальные темы меняются вместе с локацией и временем суток.

## Как играть

| Клавиша | Действие |
| --- | --- |
| WASD / стрелки | Идти |
| Space | Прыгнуть через низкую преграду |
| F | Осмотреть, поговорить, тихонько гавкнуть |
| E | Включить или выключить нюх |
| N | Переключить день и ночь |
| M | Открыть карту |
| J | Открыть улики и показания |
| P / Escape | Пауза или закрытие игровой панели |

На телефоне доступны экранные кнопки. В меню звука отдельно регулируются музыка и эффекты. Музыка запускается после первого нажатия. Найденные вещи, решения загадок и положение мопса сохраняются в браузере.

## Локальный запуск

Нужен установленный [Node.js](https://nodejs.org/). Из папки проекта:

```sh
node scripts/server.mjs
```

Откройте **http://127.0.0.1:4175/**. Этот адрес работает только на компьютере, где запущен сервер.

В Windows также можно использовать `1 - ЗАПУСТИТЬ ИГРУ.bat`. Установка пакетов и сборка не нужны. Через двойной щелчок по `index.html` игра не запускается надёжно: используются ES-модули.

Загрузите содержимое этой папки в корень отдельного репозитория. Затем включите **Settings → Pages → Deploy from a branch → main → /(root)**.

## Файлы проекта

| Файл или папка | Назначение |
| --- | --- |
| index.html | Игровой экран и панели |
| css/ | Оформление |
| js/ | Логика, отрисовка, ввод, сохранения и звук |
| assets/art/ | Фоны, карта, спрайты и портреты |
| assets/audio/ | Музыка и короткий лай |
| scripts/server.mjs | Сервер для локального запуска |
| scripts/launch.ps1 | Запуск сервера в Windows |
| scripts/generate-audio.mjs | Исходный код музыкальных дорожек |
| tests/ | Проверки физики, сценариев и аудио |
| docs/ | Проверки, исправления, материалы и публикация |

## Проверки

```sh
node --test tests/physics.test.mjs tests/gameplay.test.mjs tests/audio.test.mjs
```

[Результаты и ограничения проверки](docs/TESTING.md), [замечания и исправления](docs/USER-TEST.md), [графика и звук](docs/AUDIO-ASSETS.md).

Игра использует Canvas, обычный JavaScript и Web Audio. Сохранения привязаны к браузеру и адресу игры; локальный прогресс не переносится на опубликованный адрес автоматически.
